**Status:** Proposed

## Context

FieldCheck 1.0 ran level 1 on an OP-1 with firmware 1.7.3 (tested), on iPad with iPadOS 27.2.1, starting 2026-11-16T13:37:02Z. It compared the run with the baseline for firmware 1.7.3, level 1, from the run started 2026-11-15T16:15:58Z.

Results: 17 pass, 0 changed, 1 fail, 0 not run. Each change and failure follows, with what FieldCheck suggests. The suggestions are for a person to confirm, and FieldCheck makes no recommendation.

### `read.cost`: failed

- **Expected:** What a GetPartialObject's time grows with: its offset, or the number of reads before it. On 1.7.3 it's the offset: a read costs about what reading from the file's start to its end would (2026-11-14).
- **Used by:** Whole files read with one GetObject (ADR 0002, 2026-11-14)
- **Simulator:** the simulated OP-1 and its tests that name `read.cost`.
- **Seen:** Couldn't check: The OP-1 sent a reply that couldn't be read. (unreadableResponse(FieldTapeKit.PTPOperation.getPartialObject))
- **Suggested class, to confirm:** Incompatible. The behavior FieldTapeKit relies on is gone on this firmware.
