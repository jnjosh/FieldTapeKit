# ADR-NNNN: OP-1 firmware 1.7.3, compared with 1.7.3

**Status:** Proposed
**Date:** 2026-11-16

## Context

FieldCheck 1.0 ran level 2 on an OP-1 with firmware 1.7.3 (tested), on iPad with iPadOS 27.2.1, starting 2026-11-16T13:12:24Z. It compared the run with the baseline for firmware 1.7.3, level 2, from the run started 2026-11-15T16:16:35Z.

Results: 0 pass, 0 changed, 1 fail, 10 not run. Each change and failure follows, with what FieldCheck suggests. The suggestions are for a person to confirm, and FieldCheck makes no recommendation.

### `names.maximum`: failed

- **Expected:** A new tape with a 12-character name, using every kind of allowed character, is accepted over MTP and kept after a reconnect. A 13-character name is accepted, then cut to 12 after a reconnect (2026-11-15).
- **Used by:** TapeName.maximumLength
- **Simulator:** the simulated OP-1 and its tests that name `names.maximum`.
- **Seen:** The OP-1 disconnected during this check.
- **Suggested class, to confirm:** Incompatible. The behavior FieldTapeKit relies on is gone on this firmware.
